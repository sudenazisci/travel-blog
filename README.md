# 🌍 Travel Blog

A modern and responsive travel blog web application that allows users to explore destinations, read travel stories, and discover beautiful places around the world. The project focuses on clean UI/UX, responsive design, and an engaging reading experience.


## ✨ Features

- 🌍 Beautiful and modern travel blog interface
- 📱 Fully responsive design
- 📰 Browse travel blog posts
- 🔍 Search functionality for destinations and articles
- 📖 Detailed blog pages
- ❤️ Clean and user-friendly UI
- ⚡ Fast performance with optimized frontend
- ☁️ Deployed on Vercel

---

## 🛠️ Tech Stack

### Frontend
- React

- React Router
- CSS3

### Backend
- Node.js
- Express.js

### Database

- Mongoose
