# 🌍 Ceylan.m.e - Seyahat & Rota Günlüğü

Dünyanın dört bir yanından özenle hazırlanmış gezi rotaları, şehir rehberleri ve bağımsız seyahat yazıları içeren modern, editoryal seyahat günlüğü.

## ✨ Özellikler

- 🌍 Zarif editoryal seyahat günlüğü arayüzü
- 📱 Tüm cihazlar için tam duyarlı (responsive) tasarım
- 🎨 Sinematik tam ekran Rotalar ve Ken Burns fotoğraf sergisi
- 🔍 Şehir ve destinasyon arama deneyimi
- 📖 Detaylı gezi ve lezzet durakları rehberleri
- 💌 Entegre iletişim ve seyahat önerisi formu
- 🔒 Google AdSense ve KVKK/GDPR uyumlu sadeleştirilmiş çerez tercih paneli
- ⚡ Vite ve React ile yüksek performans

---

## 🛠️ Teknoloji Yığını

### Frontend
- React 18
- Vite
- React Router v6
- TailwindCSS
- Lucide React

### Backend
- Node.js
- Express.js
- MongoDB / Mongoose

### Yayın & Dağıtım
